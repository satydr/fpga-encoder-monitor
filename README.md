# 面向运动控制场景的 FPGA 高速编码器信号解析与在线状态预警系统

> 全国大学生嵌入式芯片与系统设计竞赛 · FPGA 创新设计赛道 · 组号 **51528**
> 平台：EGO1（Xilinx Artix-7 **XC7A35T-1CSG324C**）　工具：Vivado 2026.1　语言：纯 Verilog（**无软核、无 SDK、无 C 代码**）

---

## 一、作品是什么

一台"接在编码器线上"的**在线体检仪**。它不参与电机控制，只做旁听式监测：实时解算轴的位置与瞬时转速，并持续检查信号是否还在守规矩——A/B 相位差是否保持四分之一周期、每个零位脉冲之间的计数值是否等于额定线数、转速是否越限。一旦异常，立即锁存报警并上报故障码。

解决的实际问题：线路松脱、强电磁干扰、超速飞车等故障会让位置反馈**逐渐失真**，而运动控制器往往毫不知情，直到撞机或批次报废。

## 二、信号链（全硬件并行）

```
编码器 A/B/Z ──▶ enc_sync      两级同步（消除亚稳态）
  (J5 扩展口)    enc_debounce  200 拍计数消抖（滤毛刺）
                 enc_quad      四倍频正交解码 → step_up/dn
                        ├─▶ enc_pos    圈数 + 圈内位置（Z 相零位校准）
                        └─▶ enc_speed  M 法测速（10 ms 闸门，×2.5 用移位加法）
                                 └─▶ enc_filter  四点滑动平均（÷4 用右移）
                                        ├─▶ seg_scan      8 位数码管动态扫描
                                        ├─▶ enc_alarm     三类判别 + 锁存 + 解除武装
                                        ├─▶ oled_ssd1306  1 KB 片内显存滚动波形
                                        └─▶ uart_frame → uart_tx  11 字节定长帧 @115200 8N1
```

**三类故障判据**

| 判据 | 含义 | 状态位 |
|---|---|---|
| 超速 | 转速超过在线可配阈值 `speed_limit` | bit0 |
| 脉冲丢失 | 两个零位脉冲间隔计数超出容差 `z_gap_tol`（断线 / 丢脉冲） | bit1 |
| 非法跳变 | A/B 单拍出现两位同时跳变（相位异常） | bit2 |

## 三、实测性能（JGB37-520 真机，2026-10-05）

| 指标 | 实测值 |
|---|---|
| 测速范围 | 5 – 25000 rpm（仿真扫频标定）；真机 66 – 576 rpm |
| 测速精度 | 最高 576 rpm（电机额定 600）；稳态 500 ± 5 rpm |
| 位置分辨率 | 4 倍频（标称 1000 线 → 4000 计数/转） |
| 上传可靠性 | 115200 bps，11 字节定长帧，**30 秒 3054 帧校验和全对、零丢帧** |
| 资源占用 | **LUT 2.09%**，DSP 0，BRAM 0.5 Tile |
| 主时钟 | 100 MHz（时序收敛） |
| 超速闭环 | 阈值在线改为 400 rpm 后状态字跳变 `0x03` |

## 五、怎么复现

**1. 综合与实现**

- 直接用 Vivado 打开 `vivadoprj/vivadoprj.xpr` → Generate Bitstream；
- 或新建工程，把 `sources_1/new/*.v` 与 `constrs_1/new/ego1.xdc` 加入，器件选 `xc7a35tcsg324-1`。

**2. 烧录**

```bat
:: JTAG 在线下载（断电丢失）
burn_jtag.bat

:: 固化到 SPI Flash（需 JP2 跳线正确）
burn_flash.bat
```

**3. 接线要点（两条红线）**

- 编码器为 NPN 集电极开路，A/B/Z 各需 **4.7 kΩ 上拉到 3.3V（J5-35/36）**——**上拉顶端绝不能接 12V**；
- 编码器 0V 必须与开发板**共地（J5-33/34）**，否则一个脉冲也数不到；
- 编码器供电最低 5 V，**禁止取用板载 3.3 V**。

**4. 上位机**

```bash
python pc_host/uart_monitor.py -p COMx -b 115200   # 收数 + 实时曲线
python pc_host/fpga_config.py  -p COMx --set-speed-limit 400   # 在线改超速阈值
```

## 六、主要创新点

1. **体检式监测定位**：不控制、只旁听，把"编码器链路健康度"本身作为被测对象。
2. **纯 RTL 全链路**：从采集到显示上传无处理器参与，确定性时延、真正并行。
3. **零 DSP 算术设计**：测速 ×2.5、滤波 ÷4、波形行号映射全部用移位与加法完成，LUT 仅 2.09%。
4. **快照锁存组帧**：UART 组帧前用专用 `S_SNAP` 状态一次性锁存 6 个字段，杜绝高低字节跨进位错误。
5. **片内显存滚动波形**：1 KB BRAM（0.5 Tile）实现示波器效果，无需外挂字库与外部存储。
